An API (Application Programming Interface) 
It is a set of rules and tools that allow different software programs to communicate and share data or functionality with each other. 
In simple terms, it acts like a bridge between applications, enabling them to work together without exposing all their internal details.

Key Points About APIs

- Definition: An API is a software interface that connects two applications or systems.
- Purpose: It hides complex internal logic and exposes only useful features for developers.
- Analogy: Think of an API like a restaurant menu — you don’t see the kitchen process, but you can order items listed, and the kitchen delivers them.

⚙️ How APIs Work

Request & Response Model:

- A client (like a mobile app or website) sends a request.
- The server processes it and sends back a response.
- The API defines how this communication happens.

Example: When you click “Pay with PayPal” on an e-commerce site, the site uses PayPal’s API to securely process the payment.

📂 Types of APIs

Type	            Description	Example
Web APIs	        Enable communication over the internet	Google Maps API for location services
Library APIs	    Built into programming libraries	C++ STL functions
Operating System    APIs	Allow apps to interact with OS features	Windows API for file handling
Hardware APIs	    Connect software with hardware	Camera API to capture images


🌐 Common API Styles

- REST (Representational State Transfer): Lightweight, widely used in web apps.
- SOAP (Simple Object Access Protocol): More rigid, often used in enterprise systems.
- GraphQL: Flexible, lets clients request exactly the data they need.

✅ Benefits of APIs

- Faster Development: Developers reuse existing services instead of building from scratch.
- Security: APIs expose only necessary data, keeping systems safe.
- Scalability: Applications can integrate with multiple services easily.
- Innovation: APIs allow combining services (e.g., weather + maps) to create new apps.

⚠️ Risks & Challenges

- Dependency: If an external API changes or shuts down, your app may break.
- Security Concerns: Poorly designed APIs can expose sensitive data.
- Rate Limits: Many APIs restrict how often they can be used.

🚀 Steps to Access an API

1. Get the API endpoint (URL)
- This is the address where you send requests (e.g., https://api.openweathermap.org/data/2.5/weather).

2. Check authentication requirements
- Many APIs need an API key or OAuth token.
- Example: ?apikey=YOUR_KEY.

3. Choose the HTTP method

GET → retrieve data
POST → send new data
PUT/PATCH → update data
DELETE → remove data

4. Send the request
- Use tools like fetch() in JavaScript, requests in Python, or curl in terminal.

5. Handle the response
- Responses are usually in JSON format.
- Parse it and use the data in your app. 



🔑 What is JSON?

Definition: A lightweight data format used to store and exchange information.
Structure: Text‑based, human‑readable, and easy for machines to parse.
Usage: APIs almost always send/receive data in JSON.

⚙️ JSON Basics

Data is stored as key–value pairs
Keys are always strings (inside quotes " ").
Values can be:
- String → "Ravnoor"
- Number → 21
- Boolean → true / false
- Array → [1, 2, 3]
- Object → { "name": "Ravnoor", "age": 21 }
- Null → null

📌 Example
json
{
  "name": "Ravnoor",
  "age": 21,
  "skills": ["JavaScript", "C++", "Python"],
  "student": true
}

🛠️ Why Developers Love JSON

- Language‑independent → works with JS, Python, C++, Java, etc.
- Easy to parse → in JS:
--- JSON.parse() → convert JSON string → JS object
--- JSON.stringify() → convert JS object → JSON string

- Standard for APIs → almost every modern API uses JSON for requests/responses.

📂 Example: API Response in JSON
json
{
  "city": "Phagwara",
  "temperature": 30,
  "weather": "Sunny"
}
In JavaScript:

js
fetch("https://api.example.com/weather?city=Phagwara")
  .then(res => res.json())
  .then(data => console.log(data.weather)); // Sunny
